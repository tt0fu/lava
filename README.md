# Lava, a vulkan audio visualizer engine

![](assets/screenshot.png)

## Usage

```
lava [<path/to/config.jsonc>] [--print-config | -p] [--help | -h]
```

If no path is provided, the default config is loaded.

The [default config](./examples/default.jsonc) (which can be obtained with `lava -p`) contains the defaults for values not specified in the config file.

You can find some example configs in the [examples](./examples) directory
